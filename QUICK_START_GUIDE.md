## 🚀 FIRST VIDEO — STEP BY STEP

### Step 1: Paste Master Prompt → Answer 3 Questions
```
You: [Paste master prompt]
ChatGPT: Asks 3 questions
You: 1, 3, 1
```
- `1` = 9:16 (Shorts/Reels/TikTok)
- `3` = 60 seconds (optimal for Bryson Clips Animation style)
- `1` = Generate 10 fresh viral ideas

### Step 2: Pick Your Idea (ChatGPT gives 10)
- All are **true historical events** with a **named prop**
- Example: "3. The Boston Molasses Disaster — A storage tank burst, sending a 25-foot wave of molasses at 35 mph through Boston streets. Prop: The pressure gauge that nobody read."
- **Reply with just the number**: `3`

### Step 3: Approve Story & Shot List
- ChatGPT writes narration + shot list table
- Check: Hook at 0–3s? Prop visible? Twist question at end?
- Reply: `approve` (or `revise 2` for beat #2)

### Step 4: Generate Character Sheets (Google Flow)
For each character (usually 2–3):
1. Copy ChatGPT's character prompt
2. Google Flow → **Image** → Nano Banana 2.1 → 9:16 → 4 variants
3. Paste prompt → Generate
4. Pick best → **Save frame** → Tell ChatGPT: `Character Worker locked: [Flow image ID]`

### Step 5: Generate Video Clips (Google Flow)
For each shot (usually 6–10 shots = 6–10 clips):
1. Copy ChatGPT's video prompt for Shot 1
2. Google Flow → **Video** → Omni Flash 1.1 → 9:16 → 10s → 1 variant
3. **Attach character refs** (Ingredients) + **previous clip's last frame**
4. Paste prompt → Generate → Download when done
5. Repeat for all shots
6. Tell ChatGPT: `clips done`

### Step 6: Voiceover (Google AI Studio)
1. Copy narration script from ChatGPT
2. Google AI Studio → Gemini TTS → Voice: `Michael` → Speed: `1.15` → Generate
3. Download WAV
4. Tell ChatGPT: `voice done`

### Step 7: Edit in CapCut
1. New project → 9:16 → Import all clips + voiceover
2. Timeline: Clips in order → Trim to match shot list timestamps
3. **Auto-captions** → Style: "Quick" → Size 8% → Lower third
4. **Audio**: Voice 0dB → Music −18dB → Foley at key moments (whoosh on camera move, pop on prop)
5. **Transitions**: Cross-dissolve 0.3s only
6. Export 1080p/30fps/High bitrate
7. Tell ChatGPT: `edit done`

### Step 8: Get Thumbnail, Title, Description, Hashtags
ChatGPT outputs all 4 — copy/paste:
- **Thumbnail prompt** → Generate in Google Flow (Image, Nano Banana 2.1, 9:16)
- **5 Titles** → Pick best for each platform
- **Description** → Replace [community link] with yours
- **Hashtags** → Copy all 15

## ⚠️ COMMON PITFALLS — AVOID THESE
| Mistake | Fix |
|---------|-----|
| Pure black shadows | Always specify `#2D1B4E` in prompts |
| Jump cuts | "Gliding camera only" in every video prompt |
| Inconsistent characters | Lock character sheets BEFORE clips; use Flow Ingredients |
| Voice too slow | 1.15x speed, short sentences, present tense |
| Captions covering action | Lower third, 8% height, quick pop-in style |
| Generic titles | Front-load: `How a [PROP] [RESULT]` |
| No engagement | Pin question + reply to every comment × 60 min |
| Copying Bryson Clips Animation stories | Use **true historical events** only — public domain facts |

## 🆘 TROUBLESHOOTING QUICK REF
| Problem | Immediate Fix |
|---------|---------------|
| Flow credits out | Use Pollinations.ai (free, no login) for images; LTX Video local for video |
| Character looks different | Re-gen sheet with "EXACT same proportions as reference [Flow ID]" |
| Voice timing off | In CapCut: stretch/compress voice track to match clip duration |
| Captions out of sync | Split caption track per sentence → align each to waveform peak |
| Shadow too dark | Add "shadows deep blue-purple #2D1B4E, never pure black" to video prompt |
| Low views first week | Normal. Algorithm needs 10–15 videos to learn. Post 4×/day, engage hard. |
